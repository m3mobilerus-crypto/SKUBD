# Индекс цен на крепёж — статическая сборка

Содержимое этой папки заливается как есть в корень репозитория GitHub Pages.

```
index.html        приложение: вставка строк или загрузка файла, поиск, выгрузка в xlsx
report.html       сохранённый прогон по метизы.xlsx (bolt.ru + Пуролат), только просмотр
js/app.js         интерфейс и подбор предложений
js/parser/        разбор наименований, справочник стандартов, таблица масс, расчёт закупки
data/boltru.json  слепок прайса ТК Болт.Ру
```

Всё считается в браузере: файл никуда не отправляется.

**Что доступно в статической сборке.** Поиск идёт по слепку прайса bolt.ru. Пуролат и ШЗН
из браузера недоступны — их сайты не отдают данные напрямую (CORS), для них нужен API на сервере.
В `report.html` результат с Пуролатом есть: он посчитан заранее.

**Обновление прайса.** Прайс bolt.ru обновляется ежедневно. Пересобрать слепок:

```bash
node -e "import('./sources/boltru.js').then(m => m.refresh({ force: true }))"
node tools/build_app.js
```

и залить обновлённый `data/boltru.json`.
